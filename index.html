📚 Teoria

A função do 2º grau, também chamada de função quadrática, é representada pela expressão:

f(x) = ax² + bx + c

Onde a, b e c são números reais e a ≠ 0.

📌 Coeficientes

  • a: determina a concavidade da parábola.
    • Se a > 0, a parábola possui concavidade para cima.
    • Se a < 0, a parábola possui concavidade para baixo.
  • b: influencia a posição da parábola.
  • c: representa o ponto onde a parábola intercepta o eixo y.

📌 Discriminante (Δ)

O discriminante é calculado pela expressão:

Δ = b² − 4ac

O valor de Δ permite identificar a quantidade de raízes reais da função.

Valor de Δ Quantidade de raízes
Δ > 0 Duas raízes reais distintas.
Δ = 0 Uma raiz real (raiz dupla).
Δ < 0 Não possui raízes reais.

📌 Raízes

As raízes são os valores de x que tornam a função igual a zero, isto é, f(x)=0. No gráfico, correspondem aos pontos onde a parábola intercepta o eixo x.

📌 Vértice

O vértice é o ponto de máximo ou de mínimo da parábola.

  • Se a > 0, o vértice representa um ponto de mínimo.
  • Se a < 0, o vértice representa um ponto de máximo.

📌 Exemplo

f(x)=2x²+3x+5

  • a = 2
  • b = 3
  • c = 5

Como a > 0, a parábola possui concavidade para cima.
